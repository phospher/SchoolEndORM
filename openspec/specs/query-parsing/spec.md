## Purpose

定义类 C# 查询谓词串（如 `"a==1 && b like 'x%'"`）的词法/语法分析与内存求值契约，包括标识符字符集、运算符识别、错误输入行为与求值语义。

## Requirements

### Requirement: 标识符字符集限定为 ASCII

变量（属性名）的合法字符 MUST 限定为 ASCII 字母、ASCII 数字与下划线；首字符 MUST 为 ASCII 字母或下划线。非 ASCII 字母 MUST NOT 被当作标识符字符。

#### Scenario: 中文字符不被当作标识符

- **WHEN** 查询串中出现中文字符作为标识符的一部分
- **THEN** 分析结果与改造前一致（不将其识别为变量字符），不因改用 Unicode 判定而改变词法行为

#### Scenario: 常规标识符

- **WHEN** 查询串为 `_a1==1`
- **THEN** 识别出变量 `_a1`、运算符 `==`、常量 `1`

### Requirement: 运算符识别与区域设置无关

关键字型运算符（如 `like`）的大小写归一 MUST 使用不变文化，MUST NOT 依赖当前区域设置。

#### Scenario: 土耳其语环境识别 like

- **WHEN** 当前线程区域设置为 `tr-TR`，查询串为 `Name LIKE 'x%'`
- **THEN** 正常识别为 like 运算符，与 `en-US` 环境结果一致

### Requirement: 常量解析与区域设置无关

数值常量的合法性判定 MUST 使用不变文化，且 MUST NOT 依赖异常来完成流程控制。

#### Scenario: 逗号小数点区域解析数值

- **WHEN** 当前线程区域设置为 `de-DE`，查询串为 `Price==1.5`
- **THEN** `1.5` 被接受为合法常量

#### Scenario: 非法常量

- **WHEN** 查询串中出现既非带引号字符串、也不是合法数值的常量片段
- **THEN** 抛出查询语法异常，`Message` 含该片段原文

### Requirement: 中缀与后缀序列稳定

对同一查询串，分析结果 MUST 同时提供中缀与后缀两份元素序列，且序列内容在本次改造前后 MUST 保持一致。

#### Scenario: 复合表达式的两份序列

- **WHEN** 分析 `Student like '%' && a=='2' || ! ( b== 3 )`
- **THEN** 中缀序列与后缀序列的元素种类、值与顺序与改造前的基线快照完全一致

#### Scenario: 简单相等表达式

- **WHEN** 分析 `Id==1`
- **THEN** 中缀序列为 `Id`、`==`、`1`，后缀序列为 `Id`、`1`、`==`

### Requirement: 非法输入产生明确失败

对空输入、括号不匹配、未闭合引号、无法识别的运算符，分析 MUST 抛出异常而非静默返回，且 MUST NOT 因越界访问抛出 `IndexOutOfRangeException`。

#### Scenario: 空查询串

- **WHEN** 传入 null、空串或仅含空白的查询串
- **THEN** 抛出参数异常并携带参数名

#### Scenario: 查询串以空格结尾

- **WHEN** 查询串为 `Id==1 `（末尾含空格）
- **THEN** 分析成功，结果与 `Id==1` 相同，不抛出越界异常

#### Scenario: 括号不匹配

- **WHEN** 查询串为 `! ( b== 3`
- **THEN** 抛出查询语法异常，说明缺少右括号

#### Scenario: 无法识别的运算符

- **WHEN** 查询串包含 `=<` 之类未定义的运算符组合
- **THEN** 抛出查询语法异常并回显该运算符文本

### Requirement: 设置查询串只触发一次分析

设置待分析的查询串 MUST 只导致一次词法与语法分析。

#### Scenario: 通过构造函数传入查询串

- **WHEN** 以查询串构造分析器
- **THEN** 词法/语法分析恰好执行一次，分析结果与显式赋值查询串的路径相同

### Requirement: 内存求值语义与 SQL 语义一致

对缓存中的对象做谓词求值时，各运算符 MUST 与生成 SQL 的语义保持一致，包括比较双方均为属性时取属性值参与比较。

#### Scenario: 两个属性做字符串比较

- **WHEN** 谓词为 `Name==Nickname` 且对象的两个属性值相等
- **THEN** 求值结果为真（比较的是属性值，而非属性名字面量）

#### Scenario: 带引号常量与属性比较

- **WHEN** 谓词为 `Name=='abc'` 且属性值为 `abc`
- **THEN** 求值结果为真（常量两侧单引号被剥离）

#### Scenario: 空字符串参与比较

- **WHEN** 参与比较的字符串为空串
- **THEN** 求值正常返回布尔结果，不抛出越界异常

#### Scenario: like 通配符

- **WHEN** 谓词使用 `like` 并含 `%`、`_`、`[...]` 通配符
- **THEN** 求值结果与改造前的真值表基线一致

#### Scenario: 各类型的运算符真值表

- **WHEN** 对 `int`、`string`、`DateTime`、`bool`、`char` 属性分别应用 `==`、`!=`、`>`、`>=`、`<`、`<=`、`&&`、`||`、`!`、`like`
- **THEN** 结果与改造前的真值表基线逐项一致
